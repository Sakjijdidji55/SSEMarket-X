# Flutter 原生化技术债清单

> 开始日期：2026-11-17  
> 对应计划：`docs/flutter-native-upgrade-execution-plan.md`  
> 规则：每完成一个页面，把“暂时没做/做得不完美/后面必须补”的事项记在这里，不藏在代码注释里。

---

## 1. 全局技术债

| 编号 | 事项 | 影响 | 后续处理 |
|---|---|---|---|
| G-01 | 功能开关是编译期 `--dart-define`，不是远程配置 | 线上出问题必须发版才能切回旧页面 | 接平台远程配置或后端 `/config` 接口 |
| G-02 | 没有统一的设计 token 文件 | 各页面颜色/圆角仍可能写死，长期会漂移 | 抽 `AppTokens`（颜色/字号/间距/圆角/阴影）并逐页替换 |
| G-03 | 没有 golden test（截图对比测试）基线 | “像不像 Vue”只能靠人眼 | 每页完成时补手机/平板/桌面截图基线 |
| G-04 | 多个页面仍使用 `withOpacity` | analyzer 有 deprecation info，未来 Flutter 版本会移除 | 统一改 `.withValues(alpha: ...)` |
| G-05 | 没有统一的 API 客户端 | 新页面各建 `http.Client`，超时/错误码/401 处理不一致 | 抽 `ApiClient`，统一 base URL、超时、重试、错误映射 |
| G-06 | 版本号没有按页面递增 | 验收包和旧包版本号相同，用户容易装错 | 每个验收包递增 build number，或在文件名明确标注 |
| G-07 | 模拟器经常离线 | 页面只能靠用户真机验收，自动化 UI 回归不足 | 恢复模拟器后补 integration test/截图 |
| G-08 | 原生入口仍借小程序面板 | 用户要先打开小程序面板才能进原生页 | 后续把排行榜/音乐等入口移到主站导航或首页入口 |

## 2. 排行榜（已完成第一版）

| 编号 | 事项 | 说明 |
|---|---|---|
| R-01 | `RankingApi` 自己建 `http.Client` | 没有复用统一 ApiClient，超时/重试策略独立 |
| R-02 | 每次进入同时请求帖子榜和用户榜 | 切换 Tab 不再请求，但首屏多一次请求；可改为按 Tab 懒加载 |
| R-03 | 没有缓存 | 断网/弱网直接空列表；可缓存上次榜单 |
| R-04 | 没有分页 | 后端目前最多前 100，暂时够用；数据量变大要分页 |
| R-05 | 前三名领奖台在 1–2 条数据时的布局只做了基本兼容 | 需要补空位/单条数据的视觉验收 |
| R-06 | 入口仍在“小程序面板”里 | 点击后进原生页，但入口语义仍是“小程序”；后续移到主站导航 |
| R-07 | 未做截图对比 | 需要补手机/平板/深色模式三组截图 |

## 3. 音乐视频 / AI 配音 / AI 翻唱（进行中）

| 编号 | 事项 | 说明 |
|---|---|---|
| M-01 | 音乐上传/删除未原生化 | 当前只能播放/搜索；上传仍需 Web 端 |
| M-02 | 没有接 `audio_service` | 后台播放、锁屏控制、通知栏媒体控制还没接；现在只保证 App 内切换页面不断音 |
| M-03 | Windows/鸿蒙音频能力未验证 | `just_audio` 在 Windows/OHOS 支持不完整，需要平台兜底 |
| M-04 | TTS/翻唱结果写临时文件 | 临时文件会累积；需要定期清理/缓存目录管理 |
| M-05 | TTS/翻唱没有下载/分享按钮 | 目前只能试听；需要接文件保存/分享 |
| M-06 | TTS/翻唱轮询没有后台暂停策略 | App 切后台后 Dart 定时器可能被系统限制；需要生命周期感知 |
| M-07 | 轮询失败没有退避 | 当前固定 2 秒；网络差时应指数退避 |
| M-08 | 音色试听会打断当前音乐 | 试听复用全局播放器；需要独立试听通道或恢复原播放 |
| M-09 | 翻唱 `run_id` 语义待确认 | 当前按 Web 端传音色 id；后端若要求训练 run_id，需要映射 |
| M-10 | 没有任务取消 | 用户离开页面后任务仍在跑；需要取消/后台任务管理 |
| M-11 | `MediaApi` 的 applet base 地址写死 | 需要按环境配置，不能硬编码 |
| M-12 | 没有错误码细分 | 只显示 message；限流/未配置/任务失败没有不同引导 |
| M-13 | 视频 B 站内嵌仅 Android/iOS | Windows/鸿蒙/桌面回退浏览器；后续可接平台播放器 |
| M-14 | 视频没有画中画/后台播放 | 需要按平台补 PiP |
| M-15 | 视频 HLS 兼容性未测 | `video_player` 对 HLS 的支持依赖平台，需要真机验证 |
| M-16 | 音乐列表没有上传入口 | 与 M-01 同一问题 |

## 3.1 小说（第一版已完成）

| 编号 | 事项 | 说明 |
|---|---|---|
| N-01 | 阅读器暂未做跨段落选中 | 现在是 `SelectableText` 按段落选中；浏览器式跨段选择待 POC |
| N-02 | 阅读器暂未做段评/划线 | 段落 `commentNum` 已解析，但 UI 未接评论面板 |
| N-03 | 阅读器进度上报是 20 秒定时 + 退出 flush | 没有后台暂停/恢复策略，切后台可能多算/少算 |
| N-04 | 目录一次性拉 200 章 | 超长小说需要分页/懒加载 |
| N-05 | 小说首页骨架屏宽度用屏幕宽度估算 | 平板/桌面下可能和真实 3/4 列不齐，需要 `LayoutBuilder` |
| N-06 | 写作页第一版不支持封面、插图、富文本、本地草稿 | 目前只有书名/简介/章节标题/正文 |
| N-07 | 写作页没有提交前本地备份 | 网络失败/误退出可能丢正文 |
| N-08 | 详情页评分分布未展示 | 模型还没解析 `ratingBars` |
| N-09 | 详情页评论只能点赞/发书评 | 删评论、章评/段评、排序/搜索未做 |
| N-10 | `NovelApi` 没有统一错误码 | 失败统一显示“加载失败” |
| N-11 | 详情页“继续阅读”优先用 `progressChapterID` | 如果后端该字段为 0 且用户有本地进度，本地进度不会覆盖 |
| N-12 | 封面/正文图片没有上传链路 | 复用主站 `/auth/uploadPhotos` 待接 |
| N-13 | 没有离线章节缓存 | 目前只缓存阅读进度，不缓存正文 |


## 3.2 简历（第一版已完成）

| 编号 | 事项 | 说明 |
|---|---|---|
| S-01 | PDF 没有页内渲染 | 当前下载到临时文件后用系统 App 打开；没有 `pdfx` 页内翻页 |

| S-04 | 没有分享按钮 | 只有“下载 / 打开” |
| S-05 | 下载临时文件不清理 | 会累积在临时目录 |
| S-06 | 列表分页一次拉 200 | 简历多了会慢，应分页 |
| S-07 | 上传后返回列表不自动刷新详情缓存 | 列表会刷新，但详情页重新打开才更新 |
| S-08 | 没有权限/可见性说明 | 依赖后端返回；UI 未解释匿名/公开范围 |

## 5. 记录规则

- 新增页面时，先在本文件加一行“页面级技术债”，再写代码；
- 修掉一条就把状态改为“已解决”，不要直接删除；
- 任何“为了先跑通而临时绕过”的实现，都必须在这里留痕；
- 删除任何旧页面/旧入口前，先在聊天里明确告知用户。
